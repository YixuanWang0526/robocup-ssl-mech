# RoboCup Small Size League 机器人机械设计存档

本仓库存放我在上海交通大学 RoboCup 小型组（Small Size League）战队担任硬件组组长期间（2024.03 - 2026.03）的部分机械设计产出，用于求职作品展示。

## 我的职责

- 硬件组组长，负责整车机械结构的需求拆解、方案分工与版本规划（V1.0 稳定性 → V1.5 性能可行性 → V2.0 结构大改）。
- 负责底板、减速箱、轮系、踢球/挑球机构、嘴部与车身车壳的三维建模、装配约束设置、干涉检查与运动行程校核。
- 负责零件图绘制与制造表达：标注配合公差、材料牌号与加工技术要求，图纸随 STEP 文件交付加工厂。
- 把关整车 BOM，跟进加工与装配反馈，完成返工修改、版本更新与复装验证。

## 工程图与公差标注示例

`drawings/` 下的三张零件图用于展示我的出图与公差标注流程：国标图框、材料牌号、绘图比例与配合公差均按交付加工的标准绘制，图纸随 STEP 文件一并提交加工厂，加工厂无需追问即可下料。三件共同构成挑射机构中的过盈配合副，图纸按当时提交加工的原样导入。

| 文件 | 零件 | 材料 | 比例 | 关键标注 |
| --- | --- | --- | --- | --- |
| `drawings/kicker-iron-core_Q235A_1-1.pdf` | 挑射铁心 | Q235A | 1:1 | 两处导向孔 Ø6 +0.012/0，端部机械螺纹 |
| `drawings/guide-block_6061_5-1.pdf` | 导向件 | 6061 合金 | 5:1 | Ø6 +0.012/0 |
| `drawings/limit-shaft_SUS304_2-1.pdf` | 轴件 | SUS304 | 2:1 | Ø6 +0.027/+0.019 |

配合标注思路：孔 Ø6 +0.012/0 与轴 Ø6 +0.027/+0.019 成对标注，构成过盈量 0.007 - 0.027mm 的压装配合，用于限制挑射机构运动杆的多余自由度；孔件选 6061 便于加工，轴件选 SUS304 保证耐磨。

> 这三个零件取自 2024-2025 赛季踢球机构的中间版本，最终未进入参赛车，此处仅作为标注示例。
